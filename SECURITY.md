# Security

Please report a security problem privately through GitHub: open the **Security** tab of this repository and choose
**Report a vulnerability**. Don't open a public issue for it.

This repository is Pixelbolt's Claude Code plugin with the runtime files it starts. Problems in Pixelbolt itself can
be reported the same way on [skulitom/Pixelbolt](https://github.com/skulitom/Pixelbolt/security).
