From text to tiny worlds

Each project is a JSON recipe. Add colors to the palette, then draw with text grids or pixel, line, rectangle and ellipse operations.

{ "op": "grid", "x": 2, "y": 2,
  "rows": [".gg.", "ghhg", ".gg."] }

Each character names a palette color. A dot leaves the pixel untouched. In the editor Tab indents; press Escape and then Tab to move on with the keyboard. Save reusable grids as symbols and place them with stamp.

Reuse a previous frame with from, then draw the changes. Set each frame’s duration in milliseconds and group frames into named animations.

Open a project from your computer or try a sample on the left. Edits appear automatically. Save JSON keeps your editable recipe. Export assets downloads a ZIP ready for a game or web app, and GIF downloads the current animation at the current zoom for sharing.

Unsaved edits are kept as a draft in this browser and offered back the next time you open the studio at the same address. A draft is a safety net, not a file: use Save JSON to keep your work.

Run node bin/pixelbolt.js help for the command line, or mcp to connect an agent.
